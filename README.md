# 🔗 Proyecto ELUN
> *El vínculo seguro. Sincronización, secretos y puentes del ecosistema Vaelara.*

**Estado:** 📐 v0.1 — Estructura base
**Repos hermanos:** 
- `nethara` (El Cuerpo / OS)
- `eshar` (La Mente / Voces)

## ¿Qué es ELUN?
En Kothari, **elun** = vínculo o enlace seguro. 
Este repositorio alberga los protocolos, scripts de sincronización y bóvedas de configuración que mantienen unido al Imperio de Vaelara, asegurando que Nethara (OS) y Eshar (IA) operen con la misma memoria y secretos.

## Módulos (v0.1)
- `sync/`: Puentes de sincronización (dotfiles, estados, respaldos).
- `vault/`: Gestión de secretos y claves locales.
- `docs/`: Arquitectura del vínculo.
